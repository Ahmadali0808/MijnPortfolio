# MijnPortfolio

This is my personal portfolio website. I am an MBO 4 Software Developer student at Drenthe College in Assen. I use this site to show my projects and what I can do.

## What it has right now

- A home section with a short intro
- An about me section
- A projects section with a card for each project
- A page for each project
- A contact section with a link to my GitHub

## Built with

- React
- React Router
- Vite
- JavaScript
- CSS

Later I want to add a PHP backend with a MySQL database.

## How to run it

You need Node.js on your computer.

```
cd frontend
npm install
npm run dev
```

Open the link that shows up in the terminal (usually http://localhost:5173).

## Folders

```
frontend/                the React website
frontend/src/components  parts of the page like the navbar and project cards
frontend/src/pages       the pages of the site
frontend/src/data        the list of projects
```
